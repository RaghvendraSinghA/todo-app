# Project Name

A simple todo app with add,delete,mark-completed and drag-n-drop features.

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- [Node.js](https://nodejs.org/) (only needed)

### Installation

1. Clone the repository.

2. Install dependencies :

   ```bash
   npm install
   ```

## Run

Open `index.html` directly in your browser, or write ```open index.html``` from root directory    
of this project.  

You can also use this live-link(https://todo-app-one-smoky-99.vercel.app)
